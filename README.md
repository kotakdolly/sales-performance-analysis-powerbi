# Sales Performance Analysis Dashboard

## 📊 Project Overview

This project analyzes sales performance using Microsoft Excel and Power BI. The dashboard provides insights into sales, profit, regional performance, category performance, and monthly trends.

## 🛠️ Tools Used

- Microsoft Excel
- Power BI
- DAX
- Data Cleaning
- Data Visualization

## 📈 Key Metrics

- **Total Sales:** ₹24.22 Lakhs
- **Total Profit:** ₹8.06 Lakhs
- **Total Transactions:** 180
- **Profit Margin:** 33.3%

## 🔍 Key Insights

- South region generated ₹8.20 Lakhs in sales.
- South region generated ₹2.76 Lakhs in profit.
- Furniture generated ₹15.31 Lakhs in sales.
- Furniture had a 31.3% profit margin.
- Study Table generated ₹7.14 Lakhs in sales.
- April recorded ₹4.65 Lakhs in sales.

## 📁 Project Files

- `Sales_Performance_Analysis.xlsx` — Source data and analysis
- `sales performance analysis dashboard final.pbix` — Power BI dashboard

## 📌 Project Objective

The objective of this project was to transform raw sales data into an interactive dashboard and identify meaningful patterns in sales and profitability.
